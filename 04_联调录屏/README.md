# 联调录屏

2022 年 10–12 月备赛期间的屏幕录制，共 14 段、26 分 06 秒。
画面是 VMware 里 Ubuntu 地面站的 ROS 终端与视觉调试窗口，全部 **2512×1440 / 30 fps / H.264**。

文件名前缀是当时的自评结果：

| 前缀 | 含义 |
| --- | --- |
| `final` | 最终版调试 |
| `right` | 定点、识别结果正常 |
| `useful` | 有参考价值的中间过程 |
| `nodetected` | 当时相机没有检测到目标 |
| `fail` | 失败记录 |

## 画面里能看到什么

- 地面站五个终端的启动与操作：航点输入、模式切换、状态显示、串口舵机、视觉识别
- MAVROS 打印的 `/mavros/local_position/pose` 随飞机移动而变化——用来判断 T265 定点是否正常
- 识别节点输出的圆心偏差 `The change is x:... y:...`，以及漏检、误检时的表现
- 降落、舵机投放、切 `AUTO.LAND` 与上锁的完整时序

## 校验

`SHA256SUMS.txt` 覆盖全部 14 段：

```bash
sha256sum -c SHA256SUMS.txt        # Linux / macOS
Get-FileHash -Algorithm SHA256 *   # Windows PowerShell
```
